Front Page: 19 November 2026 — a 1024×1024 newspaper front page summing up 19 November 2026's world news in one image: 36 verified stories across 6 continents, 1 hero (GTA VI launches worldwide) + 5 illustrated leads, 30 briefs, a MARKETS panel, and a world map marking 10 cities.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (override with `MAKEFUN_OUTPUT_DIR`). Python 3.13 standard library only — no network, no pip packages, no system fonts. The program embeds its own bitmap font (`font.py`) and draws everything procedurally. Running it twice produces byte-identical output.
